# WatchGuard React Test

A simple to-do application built with React v19 and TypeScript v6 using Vite and Vitest for unit testing.

## Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by status (all, completed, incomplete)

## Installation
```
git clone https://github.com/yourusername/watchguard-react-test.git
cd watchguard-react-test
npm install
```

## Running the Application
```
npm run dev
```

## Building for Production
```
npm run build
```

## Testing
```
npm run test
```
